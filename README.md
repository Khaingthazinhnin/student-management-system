# Student Management System

A simple Student Management System built with Python. This project allows users to manage student records through a menu-driven program.

## Features

- Add student records
- View all student records
- Search for a student by ID
- Update student information
- Delete student records

## Technologies Used

- Python 3
- Visual Studio Code
- Git and GitHub

## How to Run

### Prerequisites

Make sure Python is installed on your computer.

### Steps

1. Clone this repository or download the project files.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the program:
  
   python main.py   

   If needed, use "python3 main.py" instead.

## Data Storage

Student records are stored in memory while the program is running. All records are lost when the program exits.
